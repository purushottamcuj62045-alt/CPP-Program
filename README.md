## Requirements

- A C++ compiler: [g++ (MinGW-w64)](https://www.mingw-w64.org/) on Windows, or `g++` / `clang++` on Linux and macOS
- Optional: [Visual Studio Code](https://code.visualstudio.com/) with the C/C++ extension

## How to run

1. Clone the repository:

   ```bash
   git clone https://github.com/purushottamcuj62045-alt/CPP-Program.git
   cd CPP-Program
   ```

2. Go to an assignment folder:

   ```bash
   cd Assignment1
   ```

3. Compile a program (replace `program.cpp` with the file name):

   ```bash
   g++ program.cpp -o program
   ```

4. Run it:

   ```bash
   # Windows
   .\program.exe

   # Linux / macOS
   ./program
   ```

In VS Code, you can also open a `.cpp` file and press **Ctrl + Shift + B** to build it.
